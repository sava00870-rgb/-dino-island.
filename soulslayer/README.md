# SOULSLAYER — The Shattered Realm

A browser-based top-down pixel-art action RPG prototype. This is a combat-focused action RPG, not a survival/crafting sandbox.

## Play
Open `index.html` in a browser, or enable GitHub Pages for this repository and select the `soulslayer` branch with `/soulslayer` as the site path if supported by your Pages setup. No build step or external game engine is required.

## Controls
- WASD / arrow keys: move
- Mouse: aim and attack
- Space: dash
- Q: soul burst
- Mobile: virtual joystick and action buttons

## Current playable slice
Hero movement and collision, enemy waves, melee combat, dash, area skill, XP orbs, level-up choices, passive relics, elite enemies, a multi-phase boss, HUD, mobile controls, restart and game-over state.

## Roadmap
Expand into five skill schools (fire, ice, lightning, shadow, physical), skill synergies, a larger artifact pool, equipment, skill tree, additional bosses and optional 4-player co-op. Multiplayer is not represented as implemented in this prototype.
